About

The Open Supernova Catalog (OSC) collects published photometry, spectra, and metadata for supernovae and related transients into a uniform, citable data model.

This site rebuild serves the historical public catalog corpus generated by AstroCats and the supernovae module. Event pages, the Transient Table, and the Open Astronomy Catalog API occupy their original path grammar.

Scientific citation: Guillochon et al. 2017, An Open Catalog for Supernova Data (ADS).
