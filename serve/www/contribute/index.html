Contribute

Step 1 serves the frozen public GitHub corpus. Live ingest (TNS, WISeREP, brokers) is planned for Step 2 after source-rights diligence.

Until then, contributions belong upstream:

  • File data issues on astrocatalogs/supernovae
  • Pull requests against the year repos or module tasks
  • Review duplicate and conflict tables generated by webcat
