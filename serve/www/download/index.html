Bulk event JSON lives in year-partitioned GitHub repositories. Prefer cloning the repos (or downloading these archives) rather than scraping individual event pages.

  • sne-pre-1990
  • sne-1990-1999
  • sne-2000-2004
  • sne-2005-2009
  • sne-2010-2014
  • sne-2015-2019
  • sne-boneyard (non-SN / rejected)

Single-event JSON is also available as /sne/{name}.json from this site. Programmatic access: use the OACAPI routes (local Step 1: port 8090).
